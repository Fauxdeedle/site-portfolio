tagline: An AI marketing assistant for creatives — from core chat to a full custom-agent builder
description: >-
  Ayzenberg's internal AI marketing assistant — a chat-first interface with
  prompt-suggestion cards, an expanding tool library, and a full agent
  builder for power users.
client: Ayzenberg
role: Product Designer
year: "2025"
heroImage: /images/ayz-ai-hero.png
finalDesigns:
  - /images/ayz-ai-gallery-1.png
  - /images/ayz-ai-gallery-2.png
problem: >-
  Marketers and creatives needed a single AI assistant flexible enough to
  handle unpredictable LLM output, a growing tool library, and full
  agent-building controls — across desktop and mobile — without the
  interface ever feeling like a developer tool.
process:
  - title: Designing the Core Interaction Layer
    description: >-
      Building a chat interface flexible enough for unpredictable LLM
      output meant prompt-suggestion cards as a structured entry point, so
      users don't need to know what to type, plus a "New Tools Available"
      banner that surfaces new capabilities on login without a separate
      onboarding flow.
    image: /images/ayz-ai-process-1.png
  - title: Scaling Tools & Chat History Across Breakpoints
    description: >-
      Designed the tool list and chat history to grow without
      restructuring, then solved for mobile's tightest constraint: moving
      "New Chat" to the bottom of the screen, where a thumb naturally
      lands.
    image: /images/ayz-ai-process-2.png
  - title: "Agent Builder: Custom Agents"
    description: >-
      Power users wanted precision, so the Agent Builder exposes full
      model parameters rather than hiding them. A tooltip system tied to
      every configurable option let experienced users move fast while
      giving less technical creatives a way to get up to speed without
      leaving the page.
    image: /images/ayz-ai-process-3.png
  - title: Chat Bar Explorations
    description: >-
      Prototyped moving tool-switching out of the sidebar and into the
      chat bar itself, via a labeled dropdown and an icon-based switcher.
      Neither shipped in ayz.ai, but the thinking carried directly into
      Soulmates.ai, Ayzenberg's next AI product.
    image: /images/ayz-ai-process-4.png
keyDecisions:
  - title: Exposed full model parameters instead of simplifying
    description: >-
      The Agent Builder surfaces every configurable option because hiding
      them would have undermined the feature's core value for the power
      users building these agents.
  - title: Repositioned chat history for mobile, not just resized it
    description: >-
      Research showed the pattern worked well in other LLMs, so it was
      kept — but "New Chat" moved to the bottom of the screen for mobile,
      where thumbs naturally land.
result: >-
  ayz.ai shipped with a responsive chat interface built around
  prompt-suggestion cards and an expanding tool drawer, plus an Agent
  Builder that exposed full model parameters behind a guided,
  tooltip-driven UI. The interaction patterns explored here carried
  directly into Soulmates.ai, Ayzenberg's next AI product.
---
